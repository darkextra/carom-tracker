원본에 가까운 해상도 + 빨간 공 몸체 색상 학습 + 흰/노란 수구 원형 패치 검증 + 놓친 공 전역 재탐색 + 재확인 후 ID 연결. 실제로 확인하지 못한 위치에 궤적을 그리지 않습니다. 당구대 경계를 충돌점으로 취급하지 않습니다. 원본 FPS보다 높은 분석 간격은 새로운 프레임을 만들지 않습니다. 60fps 이상 촬영 영상에서 높은 값을 선택하세요.

영상을 선택하면 시작할 수 있습니다.

④ 동영상 다운로드 (실험적)

원본 영상과 현재 궤적을 합성해 녹화합니다. 초록색 당구대 영역 점선은 저장 영상에 넣지 않습니다. 원본 길이만큼 재생하면서 처리하므로 시간이 걸리며, 현재 버전에서는 음성이 제외됩니다. iPhone Safari의 브라우저 녹화 지원에 따라 저장이 불가능할 수 있습니다.

영상 저장 기능을 확인 중입니다.

현재 버전은 원본 영상 위 시간 연동 오버레이와 좌표 저장을 지원합니다. MP4 인코딩은 실험적 브라우저 동영상 저장을 지원합니다. 영상은 서버로 전송하지 않습니다.

Safari에서는 파일 앱/사진 앱에서 영상을 선택할 수 있습니다. 영상 코덱이 브라우저에서 지원되지 않으면 MP4(H.264)로 변환한 후 사용하세요. 분석 중에는 화면을 켜 두세요.
